# Portfolio Benchmark — Pixels by Purpose

Reference for the build. Distilled from analyzing real senior/lead designer
portfolios at top companies (Stripe — Yi Xin/Artylope, Apple — Adrian Zumbrunnen,
Google/Uber — Simon Pan, plus frog/Linear/FAANG roundups). Use this to keep each
section honest against how the best designers present themselves.

## Verdict

Strong on 5 of 9 — including the two hardest to fake: real quantified work and
site-as-craft. Most portfolios fail exactly there.

### Four gaps to close, in priority order
1. **Testimonials** (❌) — the one true blank. 1–2 real quotes.
2. **First-person voice** (🟡) — rewrite the story as Priya talking, not a bio.
3. **Case-study "Insight" beat + pinned context panel** (🟡) — the senior-signal upgrade.
4. **Cessna's real role / dates / metrics** — still soft (ties to metrics-lead).

## Locked direction (context)
- Brand: **Pixels by Purpose** — every pixel has a reason.
- Aesthetic: dark, technical-editorial (near-black `#08090A`, forest-green
  `#3E9B72` accent, Fraunces serif + JetBrains Mono).
- Interaction refs: Aino (decode/scramble), Dragonfly (dark technical framing),
  Corn Revolution (data-layout / instrument panel + section rail).
- IA (8 movements): Hero → Manifesto → The Journey → How I Think → Featured Work
  → Toolbox → Playground/Design Notes → Contact.
- Target: senior/lead product design roles at Atlassian, Google, and peers.
